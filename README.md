# Strange Arts — что в проекте

Версии: Minecraft 1.21.1, NeoForge 21.1.256, Iron's Spells 1.21.1-3.16.3, irons_lib 1.21.1-2.2.0, Curios 9.4.0+1.21.1.

## Готово (код написан по реальным классам из irons_spellbooks-1.21.1-3.16.3.jar, но НЕ компилировался)
- Школа «Мистика» (`magic/StrangeSchools`) + атрибуты силы и сопротивления (`magic/StrangeAttributes`).
- Заклинания: `mystic_shield` (поглощение + кольцо искр), `mystic_whip` (луч, урон, подтягивание цели).
- Слоты Curios для Глаза Агамотто и Плаща Левитации (без функций).
- Подмена текстур портала Iron's: `assets/irons_spellbooks/textures/entity/portal/portal_round.png` и `portal_square.png`
  (10 кадров по 16x32, сейчас — сгенерированная заглушка: золотое кольцо).

## Добавлено 15 ноября
- **Глаз Агамотто** (`item/EyeOfAgamottoItem`): в слоте Curios даёт ×3 к силе мистической магии (константа `MULTIPLIER`).
- **Свитки** (`item/MysticScrollItem`, наследует свиток Iron's): текстура 64x64 из твоей картинки.
  Свитки на все уровни щита и хлыста лежат в своей вкладке «Strange Arts» (`item/ModTabs`).
- **Громовая секира** (`item/ThunderAxeItem` + `StrangeEvents`): топор из незерита; пока она в руке, электрические заклинания Iron's бьют на +4 сильнее (`LIGHTNING_BONUS`).
  Текстура секиры — заглушка, нарисуй свою: `textures/item/thunder_axe.png`.
- Рецептов крафта пока нет: все предметы берутся из творческой вкладки или командой `/give`.

## Как проверить в игре
1. Положи в `gradle.properties` свои версии, если нужно, и запусти `gradlew runClient`.
2. Творческий режим → вкладка свитков Iron's: там должны появиться «Мистический щит» и «Мистический хлыст».
3. Книга заклинаний → у школы должно быть имя «Мистика».
4. Портал: скастуй Portal и посмотри на текстуру.
